Trilium Inbox Saver — Settings

Each profile has its own server URL, ETAPI token, and inbox note. The profile selected here is the one new saves go to; you can also switch profiles from the Web2Trilium panel.
Default for Trilium Desktop is http://localhost:37840
Trilium → Options → ETAPI → Create new ETAPI token
Right-click your Inbox note in Trilium → "Copy note ID to clipboard", and paste it here. Or click "Auto-detect" below if your Inbox note has the #inbox label (Trilium sets this by default on the note you've configured as inbox in Options → Other).

Folder sync

Keeps the folders ticked below mirrored in Trilium, one note per folder holding its bookmarks as links, with a child note for each folder inside it. Firefox is the source: the notes are rewritten whenever the folders change, so edit bookmarks in Firefox, not those notes. Uses the profile selected above when you save.
The Trilium note the folders' notes go under. Right-click it in Trilium → "Copy note ID to clipboard".
A folder brings every folder inside it.

Confirmations

Ask before each of these actions. These apply to every profile and save as soon as you change them. A Trilium note with child notes is never deleted, whatever is set here.
